# 🕒 Aesthetic Desktop Clock Widget

A minimalist and aesthetic digital desktop clock widget built with **Python** and **PyQt5**. This application features a *frameless* design with a transparent, *acrylic*-style blur effect in the background.

![Application Screenshot](Storage/Screenshot1.png)

## ✨ Key Features
*   **Frameless Design:** A clean interface without the default system window frame.
*   **Transparent Blur Effect:** Utilizes the Windows API to provide an elegant, acrylic-style translucent background.
*   **Custom Font:** Uses a custom font (`LEMONMILK-LIGHT.otf`) for modern typography.
*   **Real-time Updates:** Accurately displays the current time (HH:MM:SS) and date.
*   **Standalone Executable:** Can be built into a single `.exe` file that runs without requiring a Python installation on the target machine.

## 🛠️ Technologies Used
*   [Python 3.x](https://www.python.org/)
*   [PyQt5](https://pypi.org/project/PyQt5/) (For the Graphical User Interface)
*   `ctypes` (For implementing the blur effect via Windows API)
*   [PyInstaller](https://pyinstaller.org/) (For building the desktop application)
